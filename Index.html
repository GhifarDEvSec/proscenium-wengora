Tentang

Saya adalah mahasiswa Program Studi Informatika yang saat ini menempuh semester 5, dengan fokus pembelajaran pada bidang pengembangan perangkat lunak, kecerdasan buatan, serta interaksi manusia dan komputer. Selama menjalani perkuliahan, saya berupaya untuk terus mengikuti perkembangan teknologi informasi, khususnya dalam bidang pemrograman dan pengembangan aplikasi berbasis web maupun mobile. Saya memiliki ketertarikan untuk memahami bagaimana suatu sistem atau produk teknologi dapat memberikan manfaat secara luas bagi penggunanya, dan hal tersebut menjadi motivasi saya untuk terus belajar dan mengembangkan kemampuan di bidang ini. Meskipun masih dalam proses pembelajaran dan menghadapi berbagai tantangan akademik, saya berkomitmen untuk terus berkembang dan berkontribusi secara maksimal di bidang teknologi informasi.

Pengalaman Singkat

  • Mengerjakan berbagai proyek pemrograman menggunakan bahasa Java, Python, dan C++
  • Berpartisipasi dalam kompetisi hackathon untuk mengembangkan kemampuan problem solving dan kerja tim
  • Memulai karir sebagai mahasiswa IT dengan fokus pada bidang development dan keamanan sistem (security)
